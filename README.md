# Nexolotl
Nexolotl is a social networking platform inspired by Friendster, designed to enhance human interaction, creative expression, and group collaboration. It features secure accounts, customizable profiles, collaborative posting tools, and interactive engagement to strengthen community.

 
## Objectives
- **Objective A:** To design and implement secure account management features (registration, login, logout) that ensure accessibility, privacy, and user safety.  
- **Objective B:** To develop customizable user profiles that allow creative self‑expression through layouts, avatars, backgrounds, and multimedia integration.
- **Objective C:** To create collaborative posting tools such as shared albums, bulletin boards, and daily question walls that strengthen group identity and participation.
- **Objective D:** To integrate interactive features (commenting, flash posts, log‑in streak rewards, profile views, and profile music) that boost engagement and user retention.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/Kez723Cudia/Nexolotl.git
   cd Nexolotl
   ```

2. Create and activate a virtual environment:
    ```bash
    python -m venv venv
    source venv/bin/activate   # for Mac/Linux
    venv\Scripts\activate      # for Windows
    ```

3. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
